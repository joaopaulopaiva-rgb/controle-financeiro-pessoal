# Extrato Vivo

Controle financeiro pessoal: lance gastos e receitas quando lembrar, e receba a análise dos extratos de cartão e Pix no fim do mês.

**App:** https://claude.ai/code/artifact/fb16885b-9529-45ef-9da3-c12bc900594f

## Estrutura

- `app/financas.html` — código-fonte do app (publicado como Claude Artifact). Editar aqui e republicar o mesmo arquivo para atualizar.
- `CLAUDE.md` — contexto do projeto para sessões do Claude Code: modelo de dados, fluxo de lançamento e de análise mensal.

## Como lançar um gasto/receita

- Pelo app (link acima), aba "Lançar".
- Ou conversando com o Claude ("gastei 40 no mercado hoje no pix").

## Como pedir a análise mensal

Envie o extrato do cartão e/ou do Pix (PDF, CSV, ou colado em texto) numa conversa com o Claude neste repositório. Ele cruza com os lançamentos manuais do mês e publica o resumo direto na aba "Resumo" do app.
